# طراحی نقشه ساختمان

یک وب‌اپلیکیشن تک‌فایلی برای طراحی نقشه ساختمان با دو حالت مستقل:

- **حالت ساده و خودکار**: ویزارد فارسی، تولید خودکار نقشه، اصلاح با فرمان متنی، دکمه‌های سریع، جابه‌جایی اتاق‌ها و خروجی SVG
- **حالت طراحی دستی**: افزودن اتاق، ترسیم دیوار، افزودن در و پنجره، انتخاب/جابجایی/تغییر اندازه/حذف، شبکه و چسبندگی، زوم، ذخیره و بازگردانی

## فایل‌ها

- `index.html`
- `styles.css`
- `app.js`

## اجرا

فایل `index.html` را در مرورگر باز کنید. برنامه به شبکه محلی یا سرور جداگانه نیاز ندارد.

## امکانات

- رابط فارسی راست‌به‌چپ
- ذخیره خودکار در `localStorage`
- Undo / Redo
- خروجی SVG
- چاپ تمیز برای صفحه افقی یا عمودی
- ویرایش مستقیم روی بوم SVG

## نکته

حالت خودکار برای شروع سریع مناسب است. اگر کنترل دقیق روی پلان می‌خواهید، به حالت دستی بروید و با ابزارها پلان را بسازید یا ویرایش کنید.
