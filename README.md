# نقشه‌یار

یک MVP تحت وب برای طراحی پلان ساختمان به زبان فارسی و راست‌به‌چپ.

## امکانات

- بوم SVG برای طراحی
- پن و زوم
- شبکه با مقیاس قابل تنظیم
- ابزارهای انتخاب، دیوار، اتاق، در، پنجره و پاک‌کن
- حذف با کلید `Delete`
- واگرد و از نو با `Ctrl+Z` و `Ctrl+Y`
- ذخیره پروژه در `localStorage`
- خروجی SVG

## استفاده

1. فایل `index.html` را در مرورگر باز کنید.
2. از نوار ابزار، ابزار موردنظر را انتخاب کنید.
3. برای دیوار، دو کلیک برای شروع و پایان انجام دهید.
4. برای اتاق، دو گوشهٔ مستطیل را مشخص کنید.
5. در و پنجره با یک کلیک در محل موردنظر قرار می‌گیرند.
6. برای جابه‌جایی بوم، روی فضای خالی درگ کنید.
7. با چرخ ماوس زوم کنید.

## کلیدهای میانبر

- `V` انتخاب
- `W` دیوار
- `R` اتاق
- `D` در
- `N` پنجره
- `E` پاک‌کن
- `Delete` حذف عنصر انتخاب‌شده
- `Ctrl+Z` واگرد
- `Ctrl+Y` از نو

## میزبانی

این برنامه وابستگی خارجی ندارد و فقط با سه فایل `index.html`، `styles.css` و `app.js` کار می‌کند. برای میزبانی، همین پوشه را روی هر وب‌سرور ساده‌ای قرار دهید یا فایل `index.html` را مستقیماً باز کنید.
